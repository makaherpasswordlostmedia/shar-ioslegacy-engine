# Полоса «Трассы» автоисследователя

Тяжесть кадра PSP по следам ботов и снимки вида хост-рендером. Интерфейс находки: `tools/autoexplore/INTERFACE.md` (одна строка TSV: level, x, y, z, type, weight, seed, frame, description)

| файл | что делает |
|---|---|
| `frame_model.py` | калиброванная модель кадра PSP (tools/bots/psp_calib.json, средняя ошибка 4,3 % по турам 9D/11A/11B): база уровня + город по клетке PVS + ИИ-машины + трафик + разрушение; варианты кода now / hybrid / new (гибрид + дальность по перегрузке) |
| `tracks.py frames` | по `<прогон>/trace/L<n>_s<seed>.tsv` пишет `<прогон>/findings/tracks_L<n>_s<seed>.tsv`: `heavy_frame` (>31 мс подряд меньше 10 с) и `overload_long` (≥10 с), вес 1..10 от высоты и длительности, снимок на каждую из топ-N находок |
| `tracks.py snap` | снимок вида в точке находки для любой полосы (лист 2×2 по четырём курсам); индекс `<прогон>/shots/index.tsv` |
| `hostshot.py` + `rast.c` | рендер города из `level.shr`: куски PVS1 клетки глаза ∩ конус ∩ дальность, текстуры, цвет вершин, альфа-тест, смешивание; режим `holes` — пурпурный фон (дыры под горизонтом); статистика видимости по кускам и клеткам. Не рисует небо, предметы, стейтпропы, машины, персонажей, свет |
| `selftest.py` | самопроверка на реальных данных пакета |

Ресурсы игры не коммитятся: снимки и кэши лежат в `build/` (в .gitignore). Запуск как детектор ночи: `RUN.txt`
