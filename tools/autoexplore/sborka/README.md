# Автоисследователь, полоса Сборка3 (склейка, отчёт, ночной запуск)

- `cluster.py` читает TSV находок всех полос (`tools/autoexplore/<полоса>/*.tsv`, `build/autoexplore/**`), склеивает по месту и типу (8 м, этаж 6 м), считает повторы и минимальный повтор (seed + кадр + ввод), снимок берёт из `snap=` в описании; пишет `clusters.tsv` и `ОТЧЁТ_АВТОИССЛЕДОВАТЕЛЬ_<дата>.md`.
- `night.py` берёт последний `build/final-*` (без `-release`), раздаёт полосам задания `tools/autoexplore/<полоса>/run.sh УРОВЕНЬ SEED ПАКЕТ ВЫХОД.tsv ДО_EPOCH` (8 процессов), по ходу обновляет частичный отчёт (раз в 2 мин), по окончании копирует его в `docs/handoff/` основного дерева.
- `Ночь-автоисследователь.command` двойной клик; `schedule.sh install|remove|status` ставит/снимает launchd-задание на 23:10 (не установлено, ставить только по слову).
- Общий формат находки (табуляция): уровень, x, y, z, тип, вес, seed, кадр, описание (`snap=путь`, `in=путь` в описании).
