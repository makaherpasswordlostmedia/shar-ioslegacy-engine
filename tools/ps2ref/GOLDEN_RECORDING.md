1. В своём PCSX2 открой оригинал и остановись в меню перед NEW GAME
2. System → Video Capture: сохрани видео в /Users/USER/Downloads/shar-psp/build/ps2ref/golden/m0.mp4; запись звука у тебя уже включена
3. Tools → Input Recording → New → Save State: сохрани ввод в /Users/USER/Downloads/shar-psp/build/ps2ref/golden/m0.p2m2
4. Начни NEW GAME и пройди первую миссию до Апу без ускорения; дай загрузке и репликам проиграться
5. Tools → Input Recording → Stop, затем выключи System → Video Capture; оставь рядом созданный файл SaveState.p2s
