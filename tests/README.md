# Tests

Run a check with its own script, `tests/<folder>/accept60.sh` or `gate.sh` (last line `PASS` or `FAIL`): it gives green on the fix and red on the old behavior (kept behind an `*_OLD` flag), either as a native host test on the Mac (`host.c`) or in the headless emulator through `tools/emu_run.sh`.

Folder names with a number (`msn958`, `glint941`) are the numbers of the feedback items they close. Comments inside are mostly in Russian.
